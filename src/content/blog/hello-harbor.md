做了三个项目之后发现一件事：它们各自有仓库，但没有一个地方把它们放在一起。GitHub 个人主页是列表，不是门面。于是有了这个站——Harbor，港湾，项目停泊的地方，也是我写字的地方。

## 选型：先排除现成的

先看了两个现成博客系统。Halo 主题市场很活跃，后台也漂亮，但它本质是博客系统——「项目门面」要用自定义页面硬凑，而且一个 Java 应用常驻在我的 1核2G 服务器上太紧。Solo 的皮肤库停在 2019 年，直接排除。

我真正需要的只有两件事：门面能完全按我的想法排，文章能发出去就行。在线写作不需要。这正好是静态站的形态：内容是 Git 里的 Markdown，构建时渲染成纯 HTML，没有后端、没有数据库、没有进程。所以选了 Astro + Content Collections，托管不花一分钱。

## 风格：否掉三稿才定稿

第一版延续了我在 InkFlow 和 learning-studio 里用的 Soft Mist Glass（玻璃拟态 + 紫青渐变）。做完一看：三个项目一张脸，看腻了，否掉。

然后做了六个方向的概念稿：编辑杂志、瑞士国际主义、新中式纸墨、新粗野，外加两版「清新科技」。新粗野太跳，杂志风纸感偏黄我不喜欢，最后定了清新科技：冷白底、蓝青点缀，科技感来自「仪表盘式」的信息呈现——状态面板、等宽字体标签、点阵网格——而不是特效。暗色做成了深海军蓝的夜版，不是简单反色。

## 踩过的坑

**no-JS 白屏。** 入场动画最初这样写：CSS 默认 `opacity: 0`，靠 JS 的 IntersectionObserver 加类恢复可见。某天突然意识到：禁用 JS 的用户会看到一整页空白。静态站不该有这种问题。改成有 JS 才隐藏、无 JS 默认可见，顺手还加了 `prefers-reduced-motion` 降级。

**启动假死。** 强杀 dev 进程后，`.astro/` 目录留下锁文件，下次启动无任何输出也不监听端口。查了半小时才发现是残留进程的锁。删掉 `.astro` 缓存目录就好了。这条已写进 README。

## 现在还缺什么

部署（GitHub Pages + Actions）留到最后做。RSS、sitemap、OG 卡片、自定义 404 都已就位。内容永远是最缺的——项目只有三个，文章刚开始写。慢慢来。
